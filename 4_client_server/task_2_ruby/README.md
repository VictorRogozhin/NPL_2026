# HTTP-сервер коротких ссылок на Ruby

Сервис создаёт короткие ссылки, перенаправляет на исходные адреса и показывает счётчик переходов. Сервер слушает локальный адрес 127.0.0.1, порт по умолчанию 4042.

## Архитектура программы

- Сокет TCPServer принимает по одному HTTP-запросу на соединение. Сервер читает строку запроса, заголовки и тело по Content-Length, формирует HTTP-ответ и закрывает соединение.
- POST /links принимает поле url в формате URL-encoded. Для HTTP- или HTTPS-адреса создаётся случайный восьмизначный шестнадцатеричный код с проверкой уникальности. Ответ 201 содержит JSON-поля code и short_path.
- GET /<code> возвращает 302 с заголовком Location. Счётчик увеличивается после записи ответа в сокет.
- GET /stats/<code> возвращает JSON с полем visits. Чтение статистики не увеличивает счётчик. Неизвестный путь возвращает 404, некорректный запрос — 400.
- Ссылки и счётчики хранятся в памяти до остановки сервера.
