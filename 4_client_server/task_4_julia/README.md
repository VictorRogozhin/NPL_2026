# Сетевая цепочка слов на Julia

TCP-сервер управляет одной комнатой для 2–4 игроков. Игроки ходят по очереди и продолжают цепочку слов по последней букве. Слова состоят из латинских букв, сравниваются без учёта регистра и могут использоваться в цепочке только один раз.

## Архитектура программы

- Каждое соединение обслуживается отдельной задачей Julia. Команда JOIN name регистрирует уникальное имя, а WORD word отправляет ход. Обе команды и ответы разделяются переводами строки.
- Комната хранит порядок игроков, номер текущего хода, последнее слово и множество использованных слов. Изменения общего состояния защищены блокировкой.
- Ходы доступны при двух и более участниках. Корректный ход передаёт очередь следующему игроку. Ошибка сохраняет состояние и очередь. При отключении игрок удаляется, а пустая комната сбрасывается.
- По умолчанию сервер слушает 127.0.0.1:4044. Адрес и порт можно передать аргументами. Демонстрационный клиент открывает два соединения и показывает корректные и отклонённые ходы.
