# TCP-сервер кратчайших маршрутов на D

Сервер загружает ориентированный граф. В первой строке файла перечислены имена вершин, в остальных записаны рёбра в виде `откуда куда вес`. Вес — неотрицательное целое число. Сервер слушает 127.0.0.1, порт по умолчанию 4043.

## Архитектура программы

- Граф хранится как списки исходящих рёбер. Для каждого TCP-подключения создаётся отдельный поток. Потоки читают общий граф и хранят состояние поиска локально.
- Строка `PATH start finish` запускает алгоритм Дейкстры. Ответ `OK длина вершины` содержит длину и последовательность вершин. Для недостижимой цели возвращается `NO PATH`, при ошибке — `ERR` с пояснением.
- При равных расстояниях следующая вершина выбирается по имени. Предшественник меняется только при строго меньшей длине, поэтому результат воспроизводим даже при рёбрах нулевого веса.
- Сервер собирает строки из TCP-потока и поддерживает несколько запросов на одном соединении. Демонстрационный клиент открывает два соединения.
