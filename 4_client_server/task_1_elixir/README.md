# TCP-сервер агрегации телеметрии на Elixir

Сервер принимает показания датчиков в формате UTF-8, по одной строке на сообщение. Поля разделены точкой с запятой: идентификатор датчика, целое время Unix в секундах и конечное вещественное значение. Сервер слушает 127.0.0.1, порт по умолчанию 4041.

## Архитектура программы

- Сокет `gen_tcp` работает в режиме строковых пакетов. Сервер передаёт каждый принятый сокет отдельному процессу и продолжает принимать новые подключения.
- Рабочий процесс проверяет поля и передаёт корректное показание в общий `Agent`. Агрегаты для датчиков обновляются последовательно и хранятся в памяти до остановки сервера.
- Ответ имеет формат `OK;sensor_id;count;min;max;mean;latest_timestamp`. Последнее поле содержит максимальную временную метку. Некорректная строка получает `ERR;invalid reading` и не меняет агрегаты. Строки ограничены 4096 байтами.
- Демонстрационный клиент запускает две задачи, каждая отправляет показания по своему TCP-подключению и читает ответы построчно.
