# Создание и применение бинарного патча на Nim

`create old.bin new.bin patch.bin` строит патч. `apply old.bin patch.bin restored.bin` восстанавливает целевой файл по исходнику и патчу.

## Архитектура программы

- `createPatch` находит общий префикс и непересекающийся общий суффикс. Они записываются как `COPY`, изменившаяся середина записывается как `INSERT`. Файлы читаются целиком.
- `applyPatch` проверяет заголовок и контрольную сумму исходника, выполняет операции по порядку и сверяет размер результата перед записью.
- Заголовок содержит ASCII-сигнатуру `NPAT`, один байт версии (`01`), исходный и целевой размеры (по 8 байт) и SHA-1 исходника (40 ASCII-символов в верхнем регистре).
- Все числовые поля имеют формат беззнакового 64-битного целого в порядке little-endian. Смещения отсчитываются от нуля.
- За заголовком идут операции до конца файла. `C` содержит смещение и длину, `I` содержит длину и ровно столько байтов данных. Длина каждой операции положительна. При нулевом целевом размере операций нет.
