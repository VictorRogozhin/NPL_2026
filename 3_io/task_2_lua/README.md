# Сравнение снимков каталогов на Lua

Программа сравнивает два текстовых манифеста. Каждая строка содержит относительный путь, размер в байтах и SHA-256, разделённые табуляцией.

## Архитектура программы

- Загрузчик проверяет формат строк и строит таблицу записей по путям. Повторяющиеся пути считаются ошибкой.
- Сравнение проходит по объединению путей. Путь из одного снимка означает добавление или удаление. Для общего пути изменение размера или хеша означает изменение файла.
- Размеры сравниваются как десятичные числа без потери точности. Регистр шестнадцатеричных цифр хеша не влияет на результат. Пути сравниваются в исходном виде.
- Отчёт содержит количество и отсортированные пути в каждой категории, включая неизменённые файлы.
