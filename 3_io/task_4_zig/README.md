# Бинарный индекс смещений строк на Zig

Программа читает входной файл блоками по 64 КиБ и строит индекс байтовых смещений начала строк. Единственный разделитель — LF (`0x0A`). В CRLF байт CR учитывается в смещении.

## Архитектура программы

- `buildIndex` считает прочитанные байты и переносит флаг начала строки между блоками. Смещение записывается при чтении первого байта строки. Поэтому пустой файл даёт пустой индекс, а завершающий LF не создаёт лишнюю запись.
- Индекс состоит из последовательных чисел `u64` в формате little-endian, по восемь байтов на запись, без заголовка. Первая запись непустого файла равна нулю.
- Записи отправляются в выходной файл через буфер фиксированного размера. Используемая память не растёт с размером файла или количеством строк.
- Для индекса создаётся новый файл. Если выходной путь уже существует, программа завершает работу с ошибкой, сохраняя его содержимое.
