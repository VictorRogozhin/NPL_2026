# Удаление дубликатов CSV по ключу на Perl

Программа читает CSV с заголовком и оставляет первую запись для каждого значения выбранного столбца. Разделитель задаётся аргументом и по умолчанию равен запятой. Регистр и пробелы в ключах сохраняются.

## Архитектура программы

- `read_record` читает логическую запись целиком. В кавычках допускаются разделители, переводы строк и удвоенные кавычки.
- Заголовок определяет номер ключевого столбца. Программа проверяет, что столбец встречается один раз и количество полей в записях совпадает с заголовком.
- Хеш `%seen` хранит уже встреченные значения ключа. Записи обрабатываются в порядке входного файла, поэтому первая запись каждого ключа сохраняет своё место относительно остальных.
- Результат выводится в стандартный поток вывода. Заголовок и оставшиеся записи сохраняют исходное оформление CSV.
