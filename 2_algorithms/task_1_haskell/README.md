# Рекурсивная генерация двоичного кода Грея на Haskell

По введённому целому числу n ≥ 0 программа генерирует все двоичные строки длины n в отражённом порядке Грея. Комбинации не повторяются; соседние строки отличаются ровно одним битом. Для n = 0 результат состоит из одной пустой строки.

## Архитектура программы

- `gray` — чистая рекурсивная функция. Базовый случай возвращает список из пустой строки.
- Для n > 0 функция получает результат для n − 1. К строкам предыдущего списка добавляется префикс `0`, а к строкам его перевёрнутой копии — префикс `1`. Две половины объединяются в фиксированном порядке.
- Тип `Natural` задаёт неотрицательный аргумент функции. `main` читает ввод как `Integer`, отклоняет отрицательные и нецелые значения, затем вызывает генератор.
- Результат выводится построчно, после него печатается количество комбинаций — 2ⁿ. При n = 0 пустая строка выводится отдельной строкой и сопровождается пояснением.
