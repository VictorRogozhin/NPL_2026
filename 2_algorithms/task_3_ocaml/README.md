# Выпуклая оболочка методом QuickHull на OCaml

Программа строит выпуклую оболочку множества целочисленных точек. Входной файл содержит пару координат `x y` на строку. Координаты ограничены диапазоном от −10⁹ до 10⁹ для точных вычислений в `Int64`.

## Архитектура программы

- `quickhull` удаляет повторы, выбирает крайние точки в лексикографическом порядке и разделяет остальные по сторонам начальной прямой.
- `cross` вычисляет ориентированное векторное произведение. Знак определяет сторону прямой, а для фиксированного отрезка величина произведения пропорциональна расстоянию до прямой.
- `chain` выбирает наиболее удалённую точку. При равном расстоянии выбирается лексикографически меньшая точка. Затем предикат стороны выделяет две области для рекурсивного обхода.
- `remove_collinear` убирает промежуточные точки на рёбрах. Для полностью коллинеарного набора остаются крайние точки. Вершины выводятся в порядке обхода, начиная с лексикографически минимальной.
