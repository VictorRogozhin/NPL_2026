# Максимальный поток на Clojure

Программа вычисляет максимальный поток в ориентированной сети с неотрицательными целочисленными ёмкостями. Входной файл EDN задаёт вершины в виде ключевых слов, список рёбер, исток и сток.

## Архитектура программы

- `find-path` выполняет рекурсивный поиск в глубину по рёбрам с положительной остаточной ёмкостью. Множество посещённых вершин передаётся между ветвями поиска, в том числе после возврата из тупика.
- `max-flow` реализует алгоритм Форда–Фалкерсона. Величина дополняющего потока равна минимальной остаточной ёмкости на пути.
- При дополнении уменьшается ёмкость каждого прямого шага и увеличивается ёмкость обратного. Обратный шаг позволяет перенаправить ранее проведённый поток.
- Когда дополняющего пути больше нет, накопленное значение выводится как максимальный поток. Демонстрационный пример использует обратное ребро на втором пути.
