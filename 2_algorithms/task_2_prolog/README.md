# Компоненты сильной связности на Prolog

Программа находит компоненты сильной связности ориентированного графа алгоритмом Косарайю. Граф задаётся числом вершин и списком ориентированных рёбер; вершины нумеруются от 1 до N. Внутри каждой компоненты любые две вершины взаимно достижимы.

## Архитектура программы

- `kosaraju/3` проверяет граф и выполняет два этапа алгоритма. `finish_all/6` рекурсивно обходит исходный граф, добавляя вершину в начало списка после завершения обхода её соседей. Получается порядок убывания времени завершения.
- `reverse_edge/2` меняет направление каждого ребра и формирует транспонированный граф.
- `collect_all/5` рассматривает вершины в порядке первого этапа. Для каждой ещё не посещённой вершины `visit/6` выполняет рекурсивный обход транспонированного графа и собирает одну компоненту.
- Посещённые вершины, порядок завершения и состав компоненты передаются явно через аргументы предикатов. Динамические факты не создаются.
- Для воспроизводимого вывода вершины внутри компонент и список компонент сортируются после завершения алгоритма. Изолированные вершины образуют отдельные компоненты.
- `run/0` читает термин `graph(N, Edges)` из файла и выводит компоненты. `valid_edge/2` проверяет целочисленные номера и границы вершин. Пустой граф даёт пустой список компонент.
