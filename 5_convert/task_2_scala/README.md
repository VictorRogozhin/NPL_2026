# Преобразование SQL DDL в Graphviz DOT на Scala

Каждая таблица из CREATE TABLE становится вершиной графа, а каждый внешний ключ образует ребро от ссылающейся таблицы к целевой.

## Архитектура программы

- Лексер выделяет идентификаторы, литералы и пунктуацию и пропускает комментарии. Регистр ключевых слов не учитывается. Имена таблиц и столбцов сопоставляются в исходном регистре.
- Парсер разделяет объявления по запятым только на верхнем уровне скобок. Поэтому DECIMAL(10, 2) остаётся одним объявлением столбца.
- Поддерживаются обычные объявления столбцов, PRIMARY KEY и FOREIGN KEY на один столбец. Ссылки проверяются после чтения всех таблиц.
- Генератор DOT выводит все таблицы и ориентированные связи. Подпись ребра содержит имена ссылающегося и целевого столбцов.
