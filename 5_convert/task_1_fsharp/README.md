# Преобразование GeoJSON в CSV на F#

Программа преобразует коллекцию точечных объектов GeoJSON в CSV. Первые два столбца содержат долготу и широту. За ними идут имена свойств всех объектов, отсортированные по имени.

## Архитектура программы

- Разбор JSON выполняет System.Text.Json. Программа проверяет типы FeatureCollection, Feature и Point и требует ровно две числовые координаты в каждой геометрии.
- Строковые, числовые и логические свойства преобразуются в текст. Отсутствующее свойство и null дают пустую ячейку. Вложенные массивы и объекты отклоняются с номером объекта и именем свойства.
- После проверки всех объектов программа строит объединённый набор имён свойств. Имена longitude и latitude зарезервированы для координат.
- CSV записывается в UTF-8. Поля с запятыми, кавычками и переводами строк заключаются в кавычки, внутренние кавычки удваиваются.
