# Преобразование PPM P6 в BMP на Swift

Программа преобразует RGB-изображение PPM P6 с максимальным значением канала 255 в несжатый 24-битный BMP.

## Архитектура программы

- Парсер читает заголовок на уровне байтов. Между токенами поддерживаются ASCII-пробелы и комментарии от # до конца строки. После maxval потребляется ровно один пробельный байт-разделитель.
- Размер растра должен быть равен ширине, умноженной на высоту и на три. Бинарные данные обрабатываются без текстового декодирования.
- Генератор записывает 14-байтовый заголовок BMP и 40-байтовый BITMAPINFOHEADER. Целые числа записываются в little-endian.
- Строки пикселей записываются снизу вверх, каналы меняют порядок с RGB на BGR. Каждая строка дополняется нулевыми байтами до длины, кратной четырём.
