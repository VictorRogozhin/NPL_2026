# Преобразование LDIF в CSV на Groovy

Программа преобразует текстовые записи LDIF с атрибутами вида name: value в CSV. Пустая строка разделяет записи. Выходная таблица начинается со столбца dn. Прочие имена столбцов отсортированы, отсутствующие атрибуты дают пустые ячейки.

## Архитектура программы

- Парсер собирает записи в карты атрибутов. Строка с начальным пробелом дописывается к предыдущему значению без первого пробела и без перевода строки. Имена сопоставляются без учёта регистра.
- Повторяющиеся значения сохраняются в порядке появления. В каждом значении обратная косая черта удваивается, а перед точкой с запятой добавляется обратная косая черта. Затем значения соединяются неэкранированной точкой с запятой.
- На уровне CSV ячейки с запятой, кавычкой или переводом строки заключаются в кавычки. Внутренние кавычки удваиваются. Вход и выход используют UTF-8.
