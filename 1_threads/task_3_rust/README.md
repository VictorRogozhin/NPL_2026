# Параллельная поразрядная сортировка на Rust

Программа выполняет устойчивую сортировку знаковых 32-битных целых чисел методом LSD radix sort. Четыре прохода обрабатывают байты от младшего к старшему. Для правильного порядка отрицательных чисел используется ключ `(value as u32) XOR 0x80000000`.

## Архитектура программы

- `Item` хранит значение и исходный индекс элемента. Индекс позволяет проверить сохранение порядка одинаковых значений.
- `radix_sort` разбивает текущую последовательность на непрерывные части. На каждом проходе scoped-потоки параллельно распределяют элементы своих частей по 256 локальным корзинам согласно текущему байту ключа.
- Внутри корзины сохраняется порядок чтения. Главный поток собирает корзины по возрастанию байта, а внутри одного байта — в исходном порядке частей. Поэтому каждый проход устойчив независимо от порядка завершения потоков.
- Инверсия знакового бита меняет порядок старшего байта: отрицательные числа располагаются перед неотрицательными. После четырёх проходов получается порядок по значению `i32`.
- `main` демонстрирует сортировку отрицательных чисел, нуля, повторов и крайних значений `i32`. Результат вместе с исходными индексами сравнивается с устойчивой стандартной сортировкой. Тесты также проверяют пустой ввод, разные числа потоков и сгенерированные наборы.
