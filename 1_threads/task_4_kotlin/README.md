# Параллельное вычисление корреляционной матрицы на Kotlin

Программа читает CSV с числовыми наблюдениями: строки задают объекты, столбцы — признаки, первая строка содержит заголовки. Для всех пар признаков вычисляются коэффициенты корреляции Пирсона. Результат представляет собой симметричную матрицу и сохраняется в CSV.

## Архитектура программы

- `csvFields` разбирает поля с разделителем-запятой, включая поля в кавычках и удвоенные кавычки. `readTable` проверяет заголовки, количество столбцов и конечность числовых значений. Требуется не менее двух наблюдений; переносы строк внутри полей не поддерживаются.
- `correlate` сначала вычисляет среднее каждого признака, массив отклонений от среднего и сумму квадратов отклонений.
- Для каждой пары верхнего треугольника, включая диагональ, создаётся `Callable`. Задачи выполняются фиксированным пулом `ExecutorService`. Коэффициент равен сумме произведений отклонений, делённой на произведение корней из сумм квадратов отклонений.
- Главный поток получает результаты через `Future` и записывает каждый коэффициент в позиции `[i][j]` и `[j][i]`. Рабочие задачи только читают подготовленные данные; запись матрицы выполняется последовательно. Пул закрывается в блоке `finally`.
- Для постоянного признака корреляция не определена и обозначается `NaN`, включая диагональный элемент. Для остальных признаков диагональ равна единице.
- `main` выводит матрицу и сохраняет её с заголовками в CSV. В демонстрационных данных присутствуют прямая, обратная, нулевая корреляция и постоянный признак.
