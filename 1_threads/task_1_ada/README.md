# Параллельное построение инвертированного индекса на Ada

Программа получает список текстовых файлов и строит индекс: для каждого слова сохраняет имена файлов и порядковые номера вхождений, начиная с 1. Латинские буквы приводятся к нижнему регистру; остальные символы служат разделителями. Результат записывается в текстовый файл с сортировкой слов, имён файлов и позиций.

## Архитектура программы

- `Index_File` читает один файл и формирует локальную таблицу. `Save_Word` завершает текущее слово, увеличивает его порядковый номер и добавляет позицию в список вхождений.
- Для каждого входного файла создаётся отдельная задача `Worker`. Задачи параллельно читают разные файлы и независимо строят локальные индексы.
- Защищённый объект `Shared_Index` объединяет локальные таблицы методом `Merge`. Изменение общего индекса выполняется с взаимным исключением.
- Индекс состоит из вложенных упорядоченных отображений: слово → имя файла → вектор позиций. Отображения обеспечивают алфавитный порядок слов и файлов, а позиции добавляются по порядку чтения.
- Главная процедура ждёт завершения всех задач, проверяет ошибки и получает снимок общего индекса. `Write_Index` записывает его в выходной файл. При ошибке чтения входного файла неполный индекс не записывается.
