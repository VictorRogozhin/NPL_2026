# Производитель и потребитель — Ada

Два производителя передают числа 1–10 и 11–20 через общий кольцевой буфер на 5 элементов двум потребителям. Каждый потребитель выводит количество полученных чисел и их сумму.

## Среда и запуск

Редактор: Visual Studio Code. Компилятор: GNAT 15.2.0 (официальная сборка GNAT FSF, скачана через каталог Alire; SHA-256 архива проверен).
Локальный компилятор установлен в `work/gnat` рядом с папкой `outputs`. Скрипт автоматически добавляет его в PATH текущего процесса. На другом компьютере требуется GNAT в PATH.

Из папки задания в PowerShell:

```powershell
./run.ps1
```

Команда собирает программу с предупреждениями и проверками, затем запускает её. Исходник: `src/main.adb`. Результат сборки: `build/main.exe`.

## Устройство программы

- `Buffer` — защищённый объект. `Put` разрешён при `Count < 5`, `Get` — при `Count > 0`. При закрытом барьере задача ожидает автоматически.
- `Head` и `Tail` циклически переходят от 5 к 1.
- После завершения производителей главная задача добавляет два нулевых маркера. Ноль не входит в диапазон рабочих данных. FIFO гарантирует выдачу всех рабочих чисел перед маркерами.
- Выход из вложенного блока ожидает завершения задач; после этого безопасно читаются результаты. Каждый потребитель записывает собственный элемент массива.
- Итог: 20 чисел и сумма 210. При расхождении программа завершается с ошибкой. Распределение между потребителями зависит от планировщика.
