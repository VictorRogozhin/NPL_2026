# Параллельное суммирование на Erlang

Последовательность чисел от 1 до 100 делится на четыре равные части. Для каждой части запускается отдельный процесс, который вычисляет частичную сумму и отправляет её родительскому процессу. Родитель собирает ответы и сравнивает итог с результатом последовательного суммирования.

## Архитектура программы

Программа реализована в модуле `parallel_sum`:

- `main/0` формирует список чисел, запускает параллельное суммирование и сравнивает результат с последовательным вычислением через `lists:sum/1`.
- `parallel_sum/2` проверяет делимость количества элементов на число процессов и вызывает `split/3`, которая рекурсивно разбивает список на равные части.
- Для каждой части `spawn_link/1` создаёт рабочий процесс. Он вычисляет частичную сумму и отправляет родителю сообщение `{Ref, Id, Count, Sum}`: метку вычисления, номер процесса, количество элементов и результат.
- `collect/3` принимает сообщения через `receive` и накапливает общую сумму. Метка `Ref` отделяет ответы текущего вычисления от других сообщений. После получения всех ответов функция возвращает итог; при ожидании дольше пяти секунд возникает ошибка.

Рабочие процессы не используют общий изменяемый счётчик: взаимодействие с родителем происходит через сообщения. Порядок получения ответов не влияет на итоговую сумму.
