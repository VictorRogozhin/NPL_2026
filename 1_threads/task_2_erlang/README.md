# Параллельная маркировка компонент связности на Erlang

Программа читает из текстового файла прямоугольную матрицу из нулей и единиц. Единицы обозначают занятые клетки. Компоненты определяются по четырём соседям: сверху, снизу, слева и справа; диагональное касание не соединяет клетки. Матрица разбивается на непересекающиеся полосы строк, которые обрабатываются отдельными процессами Erlang.

## Архитектура программы

- `read_matrix/1` читает матрицу и проверяет допустимые символы, непустой размер и одинаковую длину строк.
- `label/2` распределяет строки между процессами, созданными через `spawn_link/1`. Число процессов не превышает число строк.
- `mark_stripe/3` и `flood/4` локально размечают компоненты обходом четырёх соседей. Метка содержит номер полосы и номер локальной компоненты.
- Рабочие процессы отправляют координатору карты меток сообщениями с уникальной ссылкой текущего вычисления. `gather/3` собирает карты в одну таблицу.
- Координатор проверяет вертикальные соседства и объединяет связанные локальные метки через таблицу родителей. Это восстанавливает компоненты, пересекающие границы полос.
- Итоговые метки перенумеровываются при обходе матрицы по строкам. Фон сохраняет нулевую метку; результат не зависит от порядка прихода сообщений. `main/0` выводит исходную и размеченную матрицы, число компонент и сохраняет разметку в текстовый файл.
