# Параллельное суммирование на Erlang

Последовательность чисел 1–100 представлена списком и разделена на четыре равные части по 25 элементов. Четыре процесса вычисляют частичные суммы и отправляют их родительскому процессу сообщениями. Родитель получает ответы и сравнивает общий результат с последовательным суммированием.

## Среда

Visual Studio Code и Erlang/OTP 29.1.2. Для запуска на другом компьютере установите Erlang/OTP с https://www.erlang.org/downloads и добавьте его каталог `bin` в PATH. Скрипт также обнаруживает локальную установку в `work/erlang` рядом с папкой `outputs`.

## Запуск в Windows

1. Откройте Visual Studio Code.
2. Выберите **File → Open Folder** и папку `1_threads/task_2_erlang` этого проекта.
3. В проводнике слева откройте `src/parallel_sum.erl`.
4. Выберите **Terminal → New Terminal**. Подойдёт PowerShell или командная строка Windows.
5. Введите команду ниже и нажмите Enter:

```powershell
.\run.cmd
```

Скрипт компилирует исходник в `build` и запускает программу. Изменять политику выполнения PowerShell не требуется.

Ожидаются четыре ответа с частичными суммами 325, 950, 1575 и 2200. Порядок ответов может меняться. Обе итоговые суммы равны 5050; последняя строка — `CHECK PASSED: sums are equal`.

## Основные функции

- `split/3` делит список на равные части. Количество элементов должно делиться на число процессов без остатка.
- `spawn_link/1` создаёт связанные с родителем процессы. Ошибка дочернего процесса не оставляет родителя бесконечно ждать.
- `self/0` возвращает адрес родительского процесса. Оператор `!` отправляет сообщение.
- `make_ref/0` создаёт метку текущего вычисления; `receive` принимает ответы с этой меткой.
- `collect/3` собирает частичные суммы. Ограничение ожидания ответа — пять секунд.

Это демонстрация обмена сообщениями; на столь маленьком наборе данных создание процессов не обязано давать ускорение.
